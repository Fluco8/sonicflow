# 🎵 SonicFlow

A free, fast, Spotify-like music streaming web app.

## Features (MVP)
- 🔍 Search any song
- ▶️ Instant playback (full songs via YouTube audio)
- 🎨 Dark Spotify-like UI
- ⚡ Ultra-fast (Vite + React)

## Tech Stack
- **Frontend:** React + Vite
- **Styling:** Tailwind CSS
- **Audio:** Piped API (YouTube audio proxy)
- **Hosting:** Cloudflare Pages (free tier)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
